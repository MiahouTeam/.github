## 🐈 Our Main Project — Miahou

**Miahou** is an AI Harness and Agent developed to facilitate penetration testing workflows.

Initially built around **Python and Node.js**, the project transitioned to **Rust** to benefit from better performance, efficiency, memory safety, and portability.

### 🤖 AI Architecture

Miahou currently follows a **BYOA (Bring Your Own API Key)** approach.

Users can connect their own API keys to compatible AI providers, giving them control over their preferred models and infrastructure.

**What's coming next?**

We are working towards developing and integrating our own specialized LLM, designed specifically for penetration testing and offensive security operations.

Our long-term vision is to move beyond generic AI models and provide an AI built with the specific needs of security practitioners in mind.

### Core Goals

- **AI-driven workflows:** Integrating intelligent agents into penetration testing processes.
- **BYOA flexibility:** Use your own API keys and preferred AI providers.
- **Specialized AI:** A future in-house LLM tailored for pentesting.
- **Performance:** Leveraging Rust for efficient execution.
- **Portability:** Building a lightweight, cross-platform foundation.
- **Extensibility:** Supporting evolving tools and security methodologies.
